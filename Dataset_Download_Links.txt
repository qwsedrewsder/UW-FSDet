# Dataset access

This package provides links only. Dataset images, archives, and annotation files are not included.

## URPC2018

- Original competition page cited in the manuscript (historical source; inaccessible during the link check): http://www.cnurpc.org/a/js/2018/0914/102.html
- Community-hosted download page (Baidu AI Studio; not the competition's official website): https://aistudio.baidu.com/datasetdetail/227545
- Index identifying the community download page: https://github.com/Linzy0227/UVD/blob/main/README-EN.md

After downloading, verify that the split, categories, and annotation version match the experiment. The existing project expects COCO-format annotations and the cleaned files `train_clean.json` and `test_clean.json`. The external mirror is not guaranteed to provide the same test annotations or cleaning results as the local experiments. The mirror's dataset contents have not been downloaded and compared for this package.

- Baidu Netdisk link listed by the authors: https://pan.baidu.com/s/1Be8zc9UdR_Pdsyotg_vR2Q
- Baidu Netdisk access code: `4bfl`

Refer to the author repository for the latest DUO download links and access code. The publicly listed links were checked; the dataset was not downloaded again.
